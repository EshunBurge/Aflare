# Aflare — satellite fire alerts

Aflare shows fires near you using NASA satellite heat detections**, official US incident data and
National Weather Service alerts. The app will notify you when movement shows up near a place you saved.
Aflare is a Progressive Web App (PWA): a website that you can install like a normal app on iPhone,
Android, Windows, Mac and Chromebook.

**Aflare aims to make fire awareness faster.**
