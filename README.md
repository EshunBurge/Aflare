# Aflare

**Aflare aims to make fire awareness faster.**

Aflare shows fires near you using heat detected by NASA satellites with reported fires, weather alerts, forecasts, and air-quality information.
It is a Progressive Web App (PWA): one website that people can install like a normal app on iPhone, Android, Windows, Mac and Chromebook.

**Check out the app at; https://eshunburge.github.io/Aflare/**
